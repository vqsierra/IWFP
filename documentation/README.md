# Documentation

Reference materials for the California Healthy Kids Survey (CHKS) items used in the analysis. They explain where each variable came from and how to interpret it.

| File | Contents |
|---|---|
| `calschls-2019-20-crosswalk.pdf` | *Crosswalk of CalSCHLS Survey Items, 2019–20*, which maps item numbers and labels across survey years |
| `cschls_researchsum2018.pdf` | *CHKS Codebook Research Reader, 2018*, with item definitions, survey procedures and variable descriptions |
| `appendixa.pdf` | *Appendix A: Construction of Predictor Variables*, which shows how each predictor was built from CHKS items |

The CHKS documents are included unchanged, as published by the survey. They guided variable selection, cleaning and coding.
